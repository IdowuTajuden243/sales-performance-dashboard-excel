# 📊 Sales Performance Dashboard (Microsoft Excel)

## Overview

This project is an interactive Sales Performance Dashboard built in Microsoft Excel to analyze sales performance across different regions, product categories, and months.

The dashboard uses Pivot Tables, Pivot Charts, slicers, and Excel formulas to provide clear business insights.


## Dashboard Preview



## Project Objectives

- Analyze sales performance
- Compare revenue across regions
- Monitor monthly sales trends
- Create an interactive Excel dashboard
- Practice data visualization techniques


## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- SUM()
- AVERAGE()
- MAX()
- COUNTA()


## Dashboard Features

- 📈 Sales by Region
- 📅 Monthly Sales Trend
- 💰 Total Revenue KPI
- 📦 Total Orders KPI
- 📊 Average Revenue KPI
- 🏆 Highest Sales KPI
- 🎛 Interactive Region & Category Filters



## Key Insights

- Lagos generated the highest sales revenue.
- Sales were strongest in the first two months.
- Revenue varied across different regions.
- Electronics contributed significantly to total revenue.
